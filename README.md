# Student Analyzer Using Pandas

## About the Project
This project uses Python and Pandas to analyze student marks from a CSV file.

## Features
- Load student data from CSV.
- Display dataset information.
- Calculate student averages.
- Identify high performers scoring 75 or above.
- Find the top student.
- Classify student performance.

## Technologies Used
- Python
- Pandas
- CSV

## How to Run
1. Install Pandas: `pip install pandas`
2. Run the program: `python student_analyzer.py`
